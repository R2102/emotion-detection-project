# Emotion Detection Web Application

## Project Overview
This project is an AI-based web application that detects emotions from text. It acts as an Emotion Detector, developed as part of a final project for building and deploying AI applications.

## Features
* Utilizes the Watson NLP library for natural language processing and emotion detection.
* Processes text input to extract specific emotional tones (e.g., joy, sadness, anger, fear, disgust).
* Formatted output returning the dominant emotion.
* Packaged as a modular Python application (`EmotionDetection`).
* Includes unit tests to validate the accuracy of the NLP responses.
* Deployed as a web application using the Flask framework.
* Incorporates robust error handling for blank entries or invalid requests (e.g., returning 400 status codes appropriately).

## Technologies Used
* **Python 3**
* **Flask** (Web Framework)
* **Watson NLP Library** / **Embeddable AI**
* **Requests** (API calls)
* **HTML/CSS** (Frontend interface)
